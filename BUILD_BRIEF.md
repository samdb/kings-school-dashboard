# School dashboard implementation brief

Build a complete, polished, responsive private family school email dashboard. Use Python standard library backend and plain HTML/CSS/JS frontend, no build step or paid API. Work only inside this directory. Do not push, deploy publicly, alter machine config, access secrets, or read other workspace files. Use synthetic fixtures only in tracked files; actual email/profile data must stay in gitignored data/. No child names, personal emails or real school messages in source.

School branding: King's School Rochester. Family user has child in Year 3. Personalise via editable local profile (child first name, year, activities) stored in data/, not source. No automatic claim child is enrolled in a club because the club appears in a newsletter. Separate direct name match, Year 3 match, followed activity match (possible relevance), general school updates, and other-year items. Explain relevance. Ignore quoted message history for matching. Action keywords flagged as 'Possible action — check email', never falsely confirmed outstanding tasks. No inferred calendar deadlines from email receipt dates. Show received date as such. Preserve source email links.

Implement reliable read-only Gmail sync through existing gog-authenticated helper, executable configurable via environment and accounts via local profile. Command shape: gog-authenticated --account ACCOUNT --readonly --no-input gmail search QUERY --max 50 --json. JSON is {threads:[{id,date,internalDateIso,from,subject,messageCount}],has_more,nextPageToken}. Pagination --page TOKEN. Fetch each with gmail thread get ID --json, response {thread:{id,messages:[{id,internalDate,snippet,payload:{headers:[{name,value}],mimeType,body:{data:base64url},parts:[recursive MIME parts]}}]}}. Restrict school search via configurable query default from:(kings-rochester.co.uk) newer_than:180d. Read-only commands only. Bounded subprocess timeouts and pagination cap with coverage indicator. Per-account errors shown without clearing old data; no credentials in errors. Atomic persisted state. Thread/message dedup, date-order latest first. Skip attachments (display that coverage limit); decode text/plain preferred and strip HTML safely otherwise. Incoming AND outgoing context should not fabricate tasks. Prefer one latest message per thread for feed and source link. Readable excerpt without signatures/quoted history; expandable body as text only. Preserve original source.

Dashboard: elegant navy/cream/teal editorial family planner, not generic admin. Header with last successful refresh and real connection state. Separate 'For your child', 'Year group', 'All school' views, search, activity filters, possible-actions filter, save/dismiss done state local persistence without Gmail writes, accessible settings dialog, refresh button, empty/loading/error states. Default empty no fabricated school activity; explicit optional demo mode with clearly marked synthetic sample content. Mobile works. User can configure accounts/query/profile in UI. User-friendly instruction for expired Gmail auth. Auto refresh while server runs via configurable interval (default 30 minutes); retain last good state on failure. No system cron installation. Prevent overlapping refreshes.

Privacy: bind server 127.0.0.1 only; no unauthenticated network exposure. Validate Host, same-origin on all mutations, JSON types/size, whitelist routes/static assets to prevent traversal into data/. No external fonts/assets/telemetry. Email text rendered using textContent; no injected HTML. Secure local file permissions. Include .gitignore for data/ .env caches etc. README explains local-only access/SSH tunnel, setup/run, read-only sync, limitations, no full attachment parsing, no production authentication.

Add meaningful unittest coverage for matching boundaries (Year 3 vs 13; another year with direct name), quoted history, MIME decoding, dedup and failed refresh retention, API privacy/path traversal/mutation origins as feasible. Run tests and syntax checks. Return concise implementation/results and limitations. Do not git commit yet.
